DETAIL TRANSAKSI

Semua baris data yang terbaca.
Logika yang digunakan (senada XPAY Analyzer):
1. Pembacaan data — deteksi baris judul otomatis, normalisasi header, dukungan CSV / TSV / titik-koma / XLSX multi-sheet.
2. BELUM SETTLE = transaksi SUCCESS dengan flag Settled ≠ TRUE.
3. STATUS BERMASALAH = Status selain SUCCESS.
4. DUPLIKAT REFERENCE = Reference ID / Merchant Ref ID muncul lebih dari satu kali.
5. FEE TIDAK BIASA = fee per transaksi menyimpang dari rasio fee yang paling sering muncul.
6. REKAP = total per merchant dan per tanggal Settled At; angka RRN hasil notasi ilmiah Excel (mis. 6.11019E+11) dikembalikan ke bentuk penuh.
